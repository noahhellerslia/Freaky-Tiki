# Card assets

Original pixel art generated deterministically by `tools/make_cards.py` (128x176 per card - authored on a 64x88 logical grid, rasterised at 2x - transparent stepped corners). Design *inspired by* the layout of the Kenney Playing Cards Pack (CC0, kenney.nl) and Caz's Pixel Fantasy Playing Cards (CC-BY 4.0) - no pixels were copied from either pack, so no attribution is legally required for these files. Use them freely in your game. Scale with NEAREST-neighbour only, at integer multiples (2x, 3x, 4x).
